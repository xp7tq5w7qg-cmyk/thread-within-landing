A little help getting started

  1. Save the HTML file somewhere you can find it again. It’s an interactive calculator rather than a PDF pattern, and there’s nothing to install.
  2. Open it in a browser such as Safari or Chrome. If your phone’s file preview doesn’t show the pattern, try opening the saved file in a full browser.
  3. Have your washed swatch and measurements handy, then read “Before you begin” inside the calculator.

You can come back to the saved file whenever you’re planning another jumper.
